How Livepad works

  • Write your page in the HTML, CSS and JS tabs on the left. The preview on the right updates a moment after you stop typing, or right away with Run (Ctrl/Cmd + Enter).
  • Your code runs inside a sandboxed frame, so whatever you write can’t break this page.
  • The Console under the preview catches console.log output and errors, and tells you which JS line failed.
  • Phone / Tablet / Full resizes the preview so you can check how a page looks on smaller screens. Drag the divider in the middle to give either side more room.
  • Not sure what to write? Pick something from Examples. If you change your mind, hit Undo.
  • Download code saves everything as one .html file. Your code stays in your own browser and is never uploaded anywhere.
